## Guia de Exportação para Imagem

### Opção 1 — Print via navegador (mais rápido)

1. Abra cada arquivo `.html` no Chrome/Edge
2. O slide já aparece em **1080×1350px** na tela
3. Use a extensão **"Full Page Screen Capture"** ou **"GoFullPage"**
4. Exporte como PNG

### Opção 2 — Puppeteer (script automatizado)

```bash
# Instalar puppeteer (se não tiver):
npm install puppeteer

# Rodar o script de exportação:
node instagram/carrossel/export.js
```

O script `export.js` (criado junto) gera os 3 PNGs automaticamente em `instagram/carrossel/exports/`.

### Opção 3 — Figma/Canva (manual)

Se preferir editar ou ajustar antes de publicar:
1. Importe os HTMLs como referência visual
2. Recrie no Figma ou Canva usando as cores:
   - Primária: `#6366f1` (indigo)
   - Gradiente: `#6366f1 → #8b5cf6 → #a855f7`
   - Fundo escuro: `#0d0d14`
   - Fundo claro: `#f5f5fa`
   - Fonte: **Inter** (Google Fonts)
